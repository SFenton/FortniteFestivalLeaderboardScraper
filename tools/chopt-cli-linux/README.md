This fork adds JSON schema v2 with one authoritative instruction and exact
trigger metadata per activation, plus Fortnite Festival `prodrums` pathing
restricted to authored Overdrive Activation Gem windows. Normal drum gems are
worth 36 base points and cymbals are worth 42. Use `--no-pro-drums` to score the
plastic-drums chart without cymbal bonuses.
